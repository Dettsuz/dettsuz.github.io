Privacy Policy

Last updated: August 25, 2026

This policy covers the personal posting tool operated by Dettsu ("the tool"), which publishes Dettsu's own artwork to Dettsu's own social media accounts (including Pinterest) via official APIs.

What the tool does

  • The tool is used solely by its operator to publish the operator's own content to the operator's own accounts.
  • It does not provide services to other users, and no third party can use it.

Data collection

  • The tool does not collect, store, or process personal data of any third party.
  • It does not read other users' content, followers, messages, or profile data.
  • It does not use cookies, analytics, or tracking of any kind.

Data storage

  • API credentials are stored locally on the operator's own computer and are never shared.
  • Images are uploaded only for the purpose of publishing them as posts.

Data sharing

  • No data is sold, shared, or transferred to any third party.

Contact

For questions about this policy, contact Dettsu via X (@dettsuz).
